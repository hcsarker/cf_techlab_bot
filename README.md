# CF TechLab Bot

A Telegram bot for Codeforces users, providing contest reminders, problem recommendations, and user statistics.

## Features

- Contest reminders and notifications
- Problem recommendations based on user rating
- User statistics and rating tracking
- Easy integration with Telegram

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/yourusername/cf_techlab_bot.git
    cd cf_techlab_bot
    ```

2. Install dependencies:
    ```bash
    pip install -r requirements.txt
    ```

3. Set up your environment variables (see `.env.example`).

4. Run the bot:
    ```bash
    python bot.py
    ```

## Usage

- Start the bot on Telegram and use `/help` to see available commands.
- Link your Codeforces handle for personalized features.
